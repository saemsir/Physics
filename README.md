# Saem Physics — GitHub Pages site

Files:
- `index.html` — complete site structure and content
- `style.css` — responsive 3b1b-inspired visual system
- `script.js` — navigation, counters, and Web3Forms AJAX submission

## GitHub Pages
1. Create/open a GitHub repository.
2. Upload these three files to the repository root.
3. Commit to the default branch.
4. In GitHub: Settings → Pages → Deploy from branch → root folder.
